# BGSTM external results preparation
Canonical reference: https://github.com/bg-playground/BGSTM/blob/main/docs/specs/external_results_v1.md (draft).
run_evidence.py executes real unittest suites, records method-level outcomes and durations, and emits offline JSON request templates for session, cases and finish. Failed parameterized subtests are aggregated into the parent method. It does not send data or register requirements. Project UUID and server-returned session UUID must be supplied by a future authorized integration; these templates are not complete API requests. R1–R4 must be mapped to pre-existing requirements in the destination. No token or live ingestion used. Browser and portable suites have distinct artifacts and environment metadata. CI SHA refers to checkout/merge revision, not necessarily PR head. Setup failures before runner execution cannot produce case results and remain CI-level failures. UFT is not represented as executed.
